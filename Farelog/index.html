How Farelog works

Upload

Pick screenshots straight from the phone's gallery / Screenshots folder — not ones forwarded through WhatsApp or another app first. The date and time come from the file itself, so a forwarded copy loses that.

Review

Every screenshot is auto-read, then lands here for a check before anything is saved. Fix anything that's wrong, tick the boost badge by hand if it showed on screen, then Save — or Discard if it isn't an order screen.

Dashboard

Overview, Timing, Locations and Platforms — switch between them with the tabs (they all show at once on a wider screen). Filter everything to one platform with the row of buttons at the top.

Data

The full table, CSV export/import to move data between devices, and a way to wipe everything and start over.
